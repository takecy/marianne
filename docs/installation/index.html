Installation

Marianne ships as a dmg for Apple Silicon Macs. With the release dmg, installation takes under a minute and the app keeps itself current via a built-in updater. You can also build from source and install locally.

System requirements

Section titled “System requirements”
ItemRequirement
HardwareApple Silicon (M series)
macOS26.0 (Tahoe) or later
NetworkNone required at runtime — the only outbound call is the update check on launch

* Developed and tested on the author’s environment (M5, Tahoe). Behavior on older macOS releases is not verified.

Intel Macs are not supported

The distributable is built for aarch64-apple-darwin only. Launching on an Intel Mac fails with Bad CPU type in executable.

Install from the release dmg

Section titled “Install from the release dmg”

  1. Download the dmg: grab the latest Marianne_<version>_aarch64.dmg from GitHub Releases.

  2. Mount the dmg: double-click it in Finder.

  3. Drag Marianne.app into /Applications: drop it onto the Applications shortcut shown in the dmg window.

  4. Unmount the dmg: eject it from the Finder sidebar to clean up.

  5. Launch Marianne: open it from Launchpad or Spotlight.

First-launch Gatekeeper warning

Section titled “First-launch Gatekeeper warning”

The dmg is not code-signed (the maintainer hasn’t paid the Apple Developer Program’s $99/year fee), so macOS may show “Marianne cannot be opened because the developer cannot be verified” on first launch. Any one of the following one-time workarounds clears it:

  • Right-click Marianne.app in /Applications and choose Open from the context menu.

Install from source

Section titled “Install from source”

Build locally and place the app in /Applications yourself instead of using the official binary. Prerequisites match Tauri v2’s official macOS requirements.

Prerequisites

Section titled “Prerequisites”
  • Xcode Command Line Tools: xcode-select --install
  • Rust: use the installer at the official site
  • pnpm: use the installer at the official site

Build steps

Section titled “Build steps”

  1. Clone the repository: git clone https://github.com/takecy/marianne.git

  2. Install dependencies: pnpm install --frozen-lockfile

  3. Build and install locally: run pnpm install:local:unsigned. This invokes pnpm tauri build internally and copies the bundle to /Applications/Marianne.app.

  4. Approve the first-launch Gatekeeper warning: follow the same steps as in “First-launch Gatekeeper warning” above.

Source builds have auto-update disabled

This build has the updater explicitly disabled. To upgrade, re-run git pull && pnpm install:local:unsigned.

Auto-update (release dmg only)

Section titled “Auto-update (release dmg only)”

You do not need to download new dmgs by hand — Marianne checks for releases on launch and updates itself.

  • On every launch, Marianne contacts GitHub Releases for a newer build. Nothing interrupts you: when an update exists, a bell with the new version number (for example v0.3.6) appears at the bottom of the sidebar. When you are up to date, nothing is shown there at all.
  • Clicking the bell starts the update straight away — download, install, then relaunch. There is no intermediate dialog to dismiss. Progress is shown in the same spot.
  • To check on demand, use Marianne → Check for Updates… in the menu bar. The result appears briefly in the status bar at the bottom of the window.

Save before updating

Annotations in the canvas are lost when the app relaunches for an update. If annotations are present when you click the notice, Marianne asks you to confirm before it restarts — but nothing is saved for you, so export first if you want to keep your work.

You can keep working during the download. If you do, Marianne installs the update but does not restart on its own: the notice turns into Restart and waits for you to click it when you are ready.

How failures are reported depends on who asked:

  • Automatic check on launch: nothing is shown. Marianne is built to run offline, so being unable to reach GitHub is a normal state, not an error worth interrupting you for.
  • Manual check from the menu: a short message appears in the status bar for a few seconds.
  • Failed install: the bell stays in the corner with a ⚠ Failed label. Hover it for the full error message and click it to retry.

The update feed is hard-coded to https://github.com/takecy/marianne/releases/latest/download/latest.json. Draft and pre-release entries on GitHub are ignored — only published latest releases roll out.
